# 小白概念表

- **Token**：模型处理文本的基本单位，不一定等于一个汉字。
- **参数**：模型学习到的数字；参数越多通常容量越大，但训练成本也越高。
- **预训练**：从大量普通文本中学习预测下一个 token。
- **SFT**：用问答或指令数据训练模型按要求回答。
- **Epoch**：完整看一遍训练数据。
- **Batch size**：一次送进 GPU 的样本数。
- **梯度累积**：显存不足时，用多次小 batch 模拟大 batch。
- **Loss**：模型预测错误程度；下降通常是好信号，但不是唯一质量指标。
- **Checkpoint**：某个训练时刻保存的模型和训练状态。
- **推理**：用训练完成的模型生成文本。
