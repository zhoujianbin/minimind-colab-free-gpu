# 一次真实运行记录

本仓库不是纸上教程。以下数据来自一次 Google Colab 免费 T4 实跑。

## 配置

- GPU：Tesla T4
- 预训练样本：50,000
- SFT 样本：50,000
- hidden size：512
- 层数：8
- 参数量：30.03M
- 预训练序列长度：256
- SFT 序列长度：384

## 产物

- pretrain_512.pth：约 64 MiB
- full_sft_512.pth：约 64 MiB
- 预训练：3125/3125 step，最终记录 loss 3.3623
- SFT：6250/6250 step，最终记录 loss 2.3399
- 数据子集生成完成：约 01:58:19
- 预训练权重生成：约 02:20:50，估算 22 分 31 秒
- SFT 权重生成：约 02:56:08，估算 35 分 18 秒
- 两阶段总训练：约 57 分 49 秒
- T4 推理：约 35–79 token/s

时间来自同一 VM 上数据文件与权重文件的时间戳，包含少量保存和阶段切换开销。更详细的数据分布、吞吐计算和参数选择见 [data-performance-hyperparameters.md](data-performance-hyperparameters.md)。

## 质量说明

模型能生成中文并识别部分指令，但会出现病句、事实错误、重复以及答非所问。原因是参数量和训练数据都很小。这个结果适合教学：它能证明从随机初始化到可对话模型的链路完整可运行，同时直观展示数据规模与模型能力之间的关系。

## 实战中遇到的问题

1. Colab CLI OAuth 授权码不能复用。
2. CLI 创建的 GPU 在网页“管理会话”中可能显示为未知笔记本。
3. 新版 Colab Python 3.13 安装旧 requirements 会源码编译 sklearn/numpy。
4. 免费 GPU 训练结束后可能被收回，但 VM 文件暂时仍在；因此必须立即下载权重。
